Assembled 28 September 2026 from the complete v2 source and the latest DubsFC v3
update. Runtime collector, viewer and workflow files are the latest v3 files.
Packaging documentation and a clean-installation test were added.

- 96 Python unittest cases passed (0 failures), including the new full CLI
  clean-installation test and prior archive/persistence/upgrade tests.
- 26 Node tests passed (0 failures); both viewer scripts pass `node --check`.
- Test environment: Python 3.13.5, Node v22.16.0, Linux.

- That test confirms 10 synthetic matches are archived, raw unknown fields

Logs are in `docs/verification/complete_package/`.

## Contents and limitations

This is a FULL SOURCE package. No prior ZIP is required. `config.json` is excluded
on purpose. Supply yours at the root. `site/data/` is generated by sync/build.
Raw `data/` starts without match records. No files are recovered from your PC.
The optional `site/demo.json` contains clearly labelled synthetic demonstration
records and is not your match history.

The tests did not contact EA or publish a website. No hosted GitHub execution or
native Windows test was run in this packaging session. Browser verification files
elsewhere in docs are historical v3 results, not newly executed browser checks.
Checksums cannot recover deleted content or guarantee never losing uncollected
matches. Keep the actual future `data/` archive and off-device backups.
